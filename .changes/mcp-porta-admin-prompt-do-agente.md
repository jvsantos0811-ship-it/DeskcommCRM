titulo: Porta Admin da agência — prompt do agente em rascunho, pedido de publicação e voltar versão
---
A porta Admin da agência ganhou cinco ferramentas para o prompt dos agentes de IA de qualquer empresa da instalação. Dá para listar os agentes, ler o prompt no ar e o rascunho, e gravar um prompt novo **em rascunho** (nunca na versão que está no ar). Também dá para **pedir a publicação**: o pedido não publica nada; ele registra o motivo e manda um e-mail ao dono da instalação com o link da tela do agente, onde ele testa e aperta Publicar. E dá para **voltar** a uma versão que já esteve no ar, que é o mesmo que o botão Reverter do Histórico. Toda chamada fica na auditoria com o antes e o depois. Essas ferramentas existem só na porta Admin: não aparecem para as chaves de API das empresas nem para os agentes de atendimento. Nada a fazer à mão na atualização.
